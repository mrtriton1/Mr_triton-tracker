# 🔱 TRITON FINDER — by MR_TRITON

Outil OSINT de recherche de noms d'utilisateur sur les réseaux sociaux et plateformes web.

---

## ⚡ Installation

### Kali Linux
```bash
git clone https://github.com/tonpseudo/triton-finder
cd triton-finder
pip install -r requirements.txt
python3 triton.py
```

### Termux (Android)
```bash
pkg update && pkg upgrade
pkg install python
pip install -r requirements.txt
python triton.py
```
